# 🚀 ImpactLog – Backend API

ImpactLog Backend is the server-side application of the ImpactLog full-stack platform. It provides secure RESTful APIs for authentication, activity tracking, and impact management.

This project demonstrates scalable backend architecture, secure JWT authentication, and structured REST API development using Node.js and MongoDB.
